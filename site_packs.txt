# How the site fetches Phylactery (2026-10-15, session 17): a few PACKS instead of ~800 files, which took a minute at
# ~0.6 s to each file's first byte (the owner: "I want the game to be playable immediately and things get loaded as
# they're needed"). a327ex-site/renderer/tools/pack_games.py builds them into the package's manifest; the site's game
# host fetches the first before the game starts and the rest, in this order, while it plays (game_host.lua "Packs").
# The game asks game_pack_ready(name) / game_file_ready(path) for what comes later (port/items.lua, port/game.lua,
# port/audio.lua); off the site both are always true.
#
# [name] starts a pack. A line under it takes the files whose path starts with it (a folder ends with /), or every
# file of a type (*.lua). A file goes to the FIRST pack with a line that takes it; files no line takes go to the last.
