# fire: sources

Reference photographs gathered 2026-09-29 for the owner's pick. Licences are as stated on the source page; where none is stated it says so (reference use only, never ship).


NOTE ON THE FIRE SLOT: I found no open-licensed photograph of a real, burned doll (Commons, museum open access, Flickr, Digitalt Museum, Maryland archaeology all searched). Burned-state references available: straw effigies burning/burnt (straw), fire-char on wood with alligator cracking (wooden), broken bisque heads excavated at a fire-destroyed farmstead (bisque). Rag has no burned reference at all.
